### Key Idea

Create a custom Docker image using a Dockerfile that:

### What Matters

- Uses Ubuntu 24.04 as the base image
- Installs Apache2
- Changes Apache's listening port from 80 to 6400
- Exposes port 6400
- Runs Apache in the foreground

### Quick Summary

The final container should respond on: A Dockerfile is a text file containing instructions Docker uses to build an image.
