# AGENT.md

Agent guidance for this repository lives in **[CLAUDE.md](./CLAUDE.md)**.

This file exists so tools that look for `AGENT.md` / `AGENTS.md` find their way there.
It is intentionally a pointer, not a copy — the two files were previously byte-identical
duplicates, which meant every edit had to be made twice and they drifted apart.

Read, in order:

1. **[MEMORY.md](./MEMORY.md)** — project recall: structure, content sources, gotchas
2. **[CLAUDE.md](./CLAUDE.md)** — rules, architecture, content model, verification
3. **[.claude/skills/](./.claude/skills/)** — procedures for recurring tasks
